About the Project

The Smart Student Registration and Management System is a web-based application developed using Spring Boot and MySQL. It helps educational institutions register and manage student information efficiently.

Project Features

  • Student Registration
  • View Registered Students
  • Edit Student Details
  • Delete Student Records
  • MySQL Database Storage
  • REST API Integration

Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Java, Spring Boot
  • Database: MySQL
  • ORM: Spring Data JPA / Hibernate
  • Build Tool: Maven
